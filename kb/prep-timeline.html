Part 4

JavaScript Track (W18 to W19)

This track is short on purpose: about 8 hours in total, in the CS-fundamentals slot. It does not take time from DSA. Use it if a target role includes front-end or full-stack work. The KB has no JavaScript pages, so every source is outside the KB.

Week 18: the language

  • Types and coercion; == compared with ===; null compared with undefined
  • var, let, const; scope, hoisting, the temporal dead zone
  • Closures, and the loop-variable closure question
  • this rules; call, apply, bind; arrow functions
  • Prototypes, the prototype chain, and class syntax on top of it
  • Modules (ES modules and CommonJS), destructuring, spread and rest

Read: javascript.info parts 1.2 to 1.9 and MDN JavaScript Guide.

Week 19: async and coding tasks

  • The event loop: call stack, microtask queue, macrotask queue. Predict the output order of mixed setTimeout and Promise code
  • Promises, async/await, error handling
  • Node.js event loop phases; compare with Java thread-per-request and virtual threads
  • Write from memory: debounce, throttle, Promise.all, deep clone, Function.prototype.bind
  • Optional: TypeScript basics (types, interfaces, generics)

Read: Node.js event loop guide and TypeScript Handbook.

Links to the KB: the event loop connects to I/O models in kb/operating-systems/05-file-systems-and-io-models.md (planned). WebSockets connect to kb/networking/08-websockets-and-realtime.md (planned) and kb/hld/fundamentals/09-communication-patterns.md (exists).

// Example W19 task: debounce
function debounce(fn, ms) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), ms);
  };
}
