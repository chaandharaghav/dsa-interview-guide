# Software Engineering Knowledge Base

This knowledge base (KB) prepares you for software engineering interviews at product companies. It also covers the engineering topics that you use on the job.

Each topic page has two parts:

- **Fundamentals:** what the topic is and how it works.
- **Interview angle:** the questions interviewers ask, model answers, follow-up questions, and the answers that cost points.

## How to Read This KB

- Use the tabs at the top to go to a subject. Use the sidebar to go to a page in the subject.
- Press ++slash++ or ++s++ to search all pages.
- The contents panel on the right side lists the sections of the current page.
- Model answers are in collapsible blocks. Answer the question yourself first. Then click the block to compare your answer.
- The toggle in the header switches between the light theme and the dark theme.

## Reading Order for Interview Preparation

1. Start the [DSA study plan](dsa/study-plan.md). Coding rounds occur at every product company, so DSA practice runs during the whole preparation.
2. Start LLD after the DSA re-entry week. Read the LLD fundamentals, then do one case study every two days.
3. Start HLD after the LLD fundamentals. Read the HLD fundamentals in order, then do the case studies.
4. Read the P1 pages of Java, Databases, Networking, and Operating Systems. Interviewers ask about these topics in the technical rounds.
5. Prepare your behavioral stories two weeks before the first interview.

The [cross-subject study plan](study-plan.md) puts these tracks on a calendar.

## Reading Order for the Job

1. Engineering Practice: testing, code review, observability, debugging.
2. Java in depth and Databases.
3. HLD fundamentals and distributed systems.
4. Security and API Design.
