## Common assignment text

Every assignment includes this paragraph:

> Read `docs/superpowers/drafting-brief.md` in full before you start. It is binding. Then read `kb/java/README.md` for the subject's page list. The reader is a Java developer who prepares for backend interviews at product companies, so each page explains how the feature works inside, not only how to call it. State each JDK fact from the JLS, the JVM specification, a JEP, the JDK 21 javadoc, or the JDK 21 source (github.com/openjdk/jdk21u), and say which. The pages target Java 21, the version that `tools/run_java.py` uses. Where Java 22 to 25 changed a feature on your page, say what changed and cite the JEP (for example: a preview feature that became final). Check the current status of each JEP on openjdk.org today; do not rely on memory.

**Code rules.** Pure JDK code must compile and, where it has `main`, run under `tools/run_java.py`. Make concurrency demos deterministic: the printed output must be the same on every run (join threads, use latches, print results after the threads finish, do not print thread names or timings). Code that needs a library the runner does not have (Spring, Hibernate, a JDBC driver, JUnit) carries the `<!-- fragment -->` marker, and the text before it names the library and version. Compile each such block in your scratch folder against the jars in `~/.m2/repository` (Spring Boot 3.x jars are there; list the versions you used in your review note). If a jar is missing, say so in the review note.

**Spring versions.** Check the current Spring Boot and Spring Framework releases on spring.io today. Write for the current generally available major version, and state where Spring Boot 3.x differs when the difference matters in an interview (for example a renamed property or a removed class).

**Overlap rules (spec section 4).** `kb/dsa/java-toolkit.md` is the home of the collection APIs for problem solving, and `kb/dsa/foundations/` is the home of data-structure theory (hash tables, heaps, balanced trees, sorting). `java/04` explains the JDK implementations and links to both; it does not repeat the theory. `java/07` and `java/08` are the home of thread-safety primitives; `kb/lld/fundamentals/09-concurrency-in-lld.md` links to them. The N+1 problem has its home in `kb/databases/05-query-execution-and-tuning.md` (planned): `java/16` explains how JPA causes it and links there by backticked path.

Rules for links: the DSA, LLD, and HLD pages exist, so link to them. The Java pages in your batch exist when the batch ends, so link to them. Every other planned page is a backticked path from spec section 3, with its exact file name.

## Batch 1: Core Java (`kb/java/`)

Each page uses the topic template (drafting brief section 4.1).

### J1 — `01-language-core.md` (P1), `02-generics.md` (P1)

`01`: pass-by-value for primitives and references (with the swap example); `equals` and `hashCode` contract (Object javadoc), the bugs from breaking it, records' generated methods; immutability (final fields, defensive copies, the JLS 17.5 final-field guarantee); the string pool and `intern`, string literals and compile-time constants (JLS 3.10.5, 15.29); autoboxing and the `Integer` cache (the `valueOf` javadoc), `==` on boxed values, unboxing `null`; `final` and `static` (fields, methods, classes, initialization order, static nested class); nested classes (static nested, inner, local, anonymous) and the hidden outer reference and memory leak; access modifiers and overloading versus overriding rules (JLS 8.4.8, 15.12).

`02`: why generics; type erasure (what the compiler emits, bridge methods, JLS 4.6) and its consequences (no `new T[]`, no `instanceof List<String>`, overload clashes); bounded types; wildcards and PECS with `Collections.copy` as the example; invariance of `List<Number>`; raw types and heap pollution (`@SafeVarargs`); generic methods and type inference; recursive bounds (`Comparable<T>`, `Enum<E extends Enum<E>>`); reifiable types.

### J2 — `03-exceptions.md` (P1), `13-modern-java.md` (P1)

`03`: the hierarchy (`Throwable`, `Error`, `Exception`, `RuntimeException`); checked versus unchecked and the arguments for each; try-catch-finally semantics (return in finally, JLS 14.20.2); try-with-resources (JLS 14.20.3), the close order and suppressed exceptions; multi-catch and precise rethrow; exception chaining; design rules (Effective Java items 69–77, cited by item number); performance cost of exceptions (stack trace capture, the four-argument constructor); exceptions in lambdas and streams; `InterruptedException` handling.

`13`: features from Java 9 to 21 with the JEP for each: modules in brief (JEP 261), `var` (JEP 286), the `HttpClient` (JEP 321), switch expressions (JEP 361), text blocks (JEP 378), records (JEP 395), pattern matching for `instanceof` (JEP 394), sealed classes (JEP 409), record patterns (JEP 440) and pattern matching for switch (JEP 441), sequenced collections (JEP 431), virtual threads in one line linking `10-virtual-threads.md`; a short table of what Java 22–25 finalized (for example unnamed variables, JEP 456), checked on openjdk.org; how records, sealed types, and switch patterns combine for algebraic data types, with a runnable example.

### J3 — `04-collections-internals.md` (P1)

The JDK implementations, from the JDK 21 source: `ArrayList` (growth, `modCount`), `LinkedList`, `HashMap` (table, hash spreading, treeification, resize split, why the capacity is a power of two) with a link to `../dsa/foundations/04-hash-tables.md` for the theory; `LinkedHashMap` (access order, `removeEldestEntry`, link to the LRU case study); `TreeMap` (red-black, link to foundations 05); `PriorityQueue` (link to foundations 06); `ArrayDeque`; `HashSet` as a `HashMap`; `ConcurrentHashMap` in JDK 8+ (CAS on empty bins, `synchronized` on the bin head, `sizeCtl`, cooperative resize, counter cells, no null keys or values, weakly consistent iterators); `CopyOnWriteArrayList`; fail-fast iterators and `ConcurrentModificationException` (best effort, javadoc); immutable collections (`List.of`) versus unmodifiable views; `equals` and `hashCode` of collections. A comparison table of time per operation.

### J4 — `05-jvm-architecture.md` (P1), `06-memory-and-gc.md` (P1)

`05`: class loading (loading, linking, initialization; JVMS chapter 5), the class loader hierarchy since Java 9 (boot, platform, application), parent delegation and where it breaks; class initialization triggers (JLS 12.4.1); runtime data areas (JVMS 2.5): heap, method area and Metaspace, stacks, PC register, native stacks; bytecode basics with `javap -c` output for a small method; the interpreter, tiered compilation (C1, C2), inlining, escape analysis, deoptimization, OSR; JIT warm-up and its effect on benchmarks (link JMH); the JVM flags that interviews ask about.

`06`: heap layout and generations; object header size and compressed oops (labeled approximate, with the source); allocation (TLABs); GC roots and reachability; collectors in JDK 21: Serial, Parallel, G1 (regions, remembered sets, mixed collections, pause target) as the default, ZGC (generational ZGC, JEP 439, and its default status in later JDKs checked on openjdk.org), Shenandoah in brief; how to read a GC log line from `-Xlog:gc`; memory leaks in Java (static collections, listeners, `ThreadLocal` in pools, inner classes, caches) and how to find them (heap dump, `jcmd`, Eclipse MAT); `OutOfMemoryError` kinds; reference types (strong, soft, weak, phantom, `Cleaner`) and `WeakHashMap`; `finalize` deprecation (JEP 421).

### J5 — `07-concurrency-basics.md` (P1)

Threads (creation, states with the `Thread.State` javadoc, daemon threads, interruption); `synchronized` (monitors, reentrancy, what it guarantees for visibility); `wait`, `notify`, `notifyAll` and the spurious-wakeup loop; `volatile` (visibility and ordering, not atomicity; the double-checked locking fix); the Java Memory Model (JLS chapter 17): happens-before rules listed exactly (JLS 17.4.5), data races, safe publication, final fields; deadlock (the four Coffman conditions, lock ordering, `jstack` output), livelock, starvation; thread safety strategies (confinement, immutability, locking). Runnable demos must be deterministic. Link `../lld/fundamentals/09-concurrency-in-lld.md` (which links back here).

### J6 — `08-java-util-concurrent.md` (P1), `09-completablefuture.md` (P1)

`08`: executors (`ThreadPoolExecutor` parameters, queue choice, rejection policies, sizing for CPU-bound and I/O-bound work, why `Executors.newFixedThreadPool` uses an unbounded queue), shutdown; `Future`; locks (`ReentrantLock`, fairness, `tryLock`, `Condition`, `ReadWriteLock`, `StampedLock`); atomics and CAS (`AtomicInteger`, `LongAdder`, the ABA problem); synchronizers (`CountDownLatch`, `CyclicBarrier`, `Semaphore`, `Phaser`, `Exchanger`); concurrent collections and `BlockingQueue` implementations (one lock versus two locks, from the source); `ThreadLocal`; `ForkJoinPool` and work stealing.

`09`: why `CompletableFuture`; creation (`supplyAsync`, the default `ForkJoinPool.commonPool()` and when to pass an executor); composition (`thenApply`, `thenCompose`, `thenCombine`, `allOf`, `anyOf`); async versus non-async variants and which thread runs a stage; error handling (`exceptionally`, `handle`, `whenComplete`, `CompletionException` wrapping); timeouts (`orTimeout`, `completeOnTimeout`); cancellation limits; common mistakes (blocking `join` inside a stage, lost exceptions); comparison with virtual threads. Deterministic runnable examples.

### J7 — `10-virtual-threads.md` (P1), `11-concurrency-coding-problems.md` (P1)

`10`: virtual threads (JEP 444): carrier threads, mounting and unmounting, continuations, the scheduler; pinning (`synchronized` and native frames in Java 21) and JEP 491 (Java 24) that removes pinning for `synchronized`, checked on openjdk.org; when virtual threads help (I/O-bound, thread-per-request) and when not (CPU-bound, pooling them); `ThreadLocal` costs; structured concurrency and scoped values: preview in Java 21, then their current status in later JDKs (scoped values final in JDK 25 by JEP 506; structured concurrency still preview: check), with the "preview in Java 21" label and `<!-- preview -->` markers where code uses them; Spring Boot support for virtual threads (`spring.threads.virtual.enabled`).

`11`: classic problems, each with the problem, a correct runnable solution, the common wrong solution and why it fails: odd-even printing with two threads; printing in order with three threads; producer-consumer with `wait`/`notify` and with `BlockingQueue`; bounded blocking queue from scratch; reader-writer lock from scratch; thread-safe singleton (holder idiom, enum, double-checked locking with `volatile`); dining philosophers; a rate-limited executor (link `../hld/fundamentals/13-rate-limiting-algorithms.md`); a simple thread pool from scratch. Output deterministic.

### J8 — `12-functional-and-streams.md` (P1), `14-reflection-and-annotations.md` (P2)

`12`: lambdas (target typing, effectively final, capture), method references (four kinds); `java.util.function` interfaces; streams (laziness, intermediate and terminal operations, short-circuiting, stateful operations, ordering); collectors (`groupingBy`, `partitioningBy`, `toMap` with merge, `teeing`); `Optional` and its intended use; primitive streams; parallel streams (`ForkJoinPool.commonPool()`, splitting, when they are slower, side effects); common mistakes (stream reuse, side effects in `map`, `peek` for logic). Link `../dsa/java-toolkit.md` for DSA idioms instead of repeating them.

`14`: the reflection API (`Class`, `Method`, `Field`, `setAccessible` and strong encapsulation since Java 16/17, JEP 396 and JEP 403); performance and `MethodHandle`; annotations (retention, targets, repeatable, meta-annotations), annotation processors (compile time, Lombok in brief), runtime annotation reading; dynamic proxies (`java.lang.reflect.Proxy`) with a runnable example, and how Spring uses JDK proxies and CGLIB (link `17-spring-core.md`).

## Batch 2: Persistence, Spring, and tooling (`kb/java/`)

### J9 — `15-io-nio-and-serialization.md` (P3), `23-build-tools.md` (P2)

`15`: byte and character streams, decorators, buffering; `java.nio.file` (`Files`, `Path`); NIO buffers and channels, selectors in brief; memory-mapped files; Java serialization (`Serializable`, `serialVersionUID`, deserialization attacks, serialization filters, JEP 290 and JEP 415) and why to prefer JSON or Protobuf.

`23`: Maven (lifecycle and phases, plugins and goals, the POM, dependency scopes, transitive resolution with "nearest wins", `dependencyManagement` and BOMs, `mvn dependency:tree`, exclusions); Gradle (tasks, configurations `implementation` versus `api`, conflict resolution "highest version wins", the wrapper); version conflicts and how to diagnose `NoSuchMethodError`; reproducible builds in brief. Build files are `xml` and `kotlin`/`groovy` blocks, not Java.

### J10 — `16-jdbc-jpa-and-hibernate.md` (P1), `19-spring-data-and-transactions.md` (P1)

`16`: JDBC (connections, `PreparedStatement` and SQL injection, batching, transactions, connection pools such as HikariCP); JPA and Hibernate: the persistence context, entity states (transient, managed, detached, removed), dirty checking and flush modes, lazy and eager loading, `LazyInitializationException`, the N+1 problem and its fixes (`JOIN FETCH`, entity graphs, batch fetching), the first-level and second-level caches, optimistic locking with `@Version`, the open-session-in-view debate. Link `../lld/` repository patterns where relevant.

`19`: Spring Data repositories (derived queries, `@Query`, paging, projections); `@Transactional`: how the proxy works, propagation types (all seven, with when to use `REQUIRES_NEW`), isolation levels (link `kb/databases/04-transactions-and-isolation.md` as a backticked path), read-only, rollback rules (unchecked by default), the self-invocation pitfall and its fixes, `@Transactional` on private methods, transactions and `@Async`, transaction synchronization and `@TransactionalEventListener`.

### J11 — `17-spring-core.md` (P1), `18-spring-boot.md` (P1)

`17`: IoC and DI (constructor injection and why it is preferred), the `ApplicationContext`, bean definition sources (`@Component` scanning, `@Bean`), scopes (singleton, prototype, request, session) and the prototype-in-singleton problem, the bean lifecycle (instantiation, population, `Aware`, `BeanPostProcessor`, init and destroy callbacks), circular dependencies (and the Spring Boot 2.6+ default that forbids them), AOP (proxies, JDK versus CGLIB, pointcuts, advice types, why internal calls skip the proxy), events.

`18`: auto-configuration (`@SpringBootApplication`, conditional annotations, the `AutoConfiguration.imports` file), starters, externalized configuration and property precedence, profiles, `@ConfigurationProperties` versus `@Value`, Actuator endpoints and exposure, embedded servers, graceful shutdown, packaging (fat jar, layered jars), startup time and native images in brief, testing slices (`@SpringBootTest`, `@WebMvcTest`, `@DataJpaTest`).

### J12 — `20-spring-web-and-rest.md` (P1), `21-spring-security.md` (P2)

`20`: the request flow (filter chain, `DispatcherServlet`, handler mapping, handler adapter, argument resolvers, message converters, view resolution or `@ResponseBody`); controllers, path and query parameters, request bodies; validation (Jakarta Bean Validation, `@Valid`, `@Validated`); exception handling (`@ExceptionHandler`, `@ControllerAdvice`, `ProblemDetail` and RFC 9457); filters versus interceptors; `RestClient` and `WebClient` in brief; WebFlux in one section (when reactive helps). `21`: the `SecurityFilterChain` and `DelegatingFilterProxy`; authentication (`AuthenticationManager`, providers, `UserDetailsService`, password encoding with BCrypt); authorization (request matchers, method security `@PreAuthorize`); sessions versus stateless JWT; the OAuth2 resource server with JWT validation; CSRF and CORS (what each protects); common mistakes. The security concepts link `kb/security/` pages by backticked path.

Spring Cloud components and their current status (check spring.io; for example which Netflix components are in maintenance): service discovery (Eureka, Kubernetes), configuration (Config Server), gateway (Spring Cloud Gateway), resilience (Resilience4j: circuit breaker, retry, bulkhead, rate limiter), declarative clients (OpenFeign and the HTTP interface clients), distributed tracing (Micrometer Tracing, OpenTelemetry), messaging (Spring Cloud Stream, Spring Kafka in brief).
